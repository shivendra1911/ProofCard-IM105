## Slide 2: PARIKSHA : Proof of Code (Problem & Solution)

> *“Proof of Skill, Not a Template Resume.”*

### 1. The Real-World Crisis
* **The Tutorial & AI-Dump Epidemic:** 90%+ fresher portfolios consist of cloned public repositories (Code-with-Harry, Spotify clones, generic CRUD) or unverified ChatGPT prompt dumps.
* **The Pedigree Filter Penalty:** Legacy ATS platforms filter out 84% of resumes from Tier-2 and Tier-3 institutions based purely on university brand names, completely blind to genuine builders.
* **The MBA / Non-Tech Blind Spot:** Non-technical candidates inflate resume bullets (*"+32% conversion lift"*) with zero accountability for unit economics, baseline traffic, or cross-functional trade-offs.

### 2. The Pariksha Solution
* **Zero-Bias Competency Ledger:** Replaces the static resume with an indisputable, evidence-based credential backed by raw source code forensics and strategic business deliverables.
* **Dual-Stream Adaptive Intelligence:** Dynamically bifurcates evaluation between:
  * **⚡ Technical Branch:** Abstract Syntax Tree (AST) parsing, McCabe cyclomatic complexity, and Git-DNA commit cadence analysis.
  * **💼 Non-Technical Branch:** Executive case defense (unit economics, stakeholder conflict, 48-hour growth drop triage). Zero code syntax required.
* **3D Verifiable ProofCard:** Public digital credential backed by an immutable SHA-256 hash and scannable QR verification link.

## Slide 3: Technical Approach & Architecture

### 1. Dual-Stream Forensic Analysis Pipeline
* **Abstract Syntax Tree (AST) Inspection:** Parses Python and TypeScript source code into structural syntax nodes without executing untrusted code in sandboxes. Identifies $O(N \log N)$ complexity, sliding windows, and deep nesting.
* **Git-DNA Cadence Forensics:** Analyzes commit timestamp distributions over time. Calculates the **Refactoring Deletion Ratio** ($> 15\%$ deletion ratio proves authentic development vs. single-burst 99% tutorial dumps).
* **Adversarial Security Shield:** Scans code comments and documentation for prompt injection jailbreak directives (`FLAGGED_ADVERSARIAL_INJECTION`) and tokenizes code against public tutorial fingerprint archives.

### 2. The 100-Mark Fragmented Ledger & Dynamic Viva
$$\text{Composite Score (100)} = \text{Resume}(10) + \text{Project}(15) + \text{Originality}(20) + \text{Viva}(10) + \text{Usability}(10) + \text{Fit}(15) + \text{Architecture}(10) + \text{Discipline}(10)$$

* **Pending-Aware Integrity:** Viva marks strictly remain at **$0 / 10$ (Pending Live Viva)** until defended live. Unearned points are never pre-computed.
* **Interactive Viva Defense Arena:** 3-minute timed oral/written defense with Web Speech API voice dictation targeting candidate-specific architectural trade-offs or business case dilemmas.
* **High-Contrast 5-Axis Competency Radar:** High-contrast bold jet-black labels (`#0F172A`, 800 weight) with crisp white halo strokes for razor-sharp visibility on white backgrounds.

## Slide 4: Feasibility and Viability

### 1. Architectural Resilience & Dual-Engine Design
* **Deterministic Offline Engine (Zero-Failure Demo):** Functions 100% locally using Python AST, scikit-learn TF-IDF burstiness models, and rule-based extractors. **Zero external API dependencies** required for core grading—eliminates network drops and rate limit failures.
* **Cloud AI Engine (Google Gemini 2.5 Flash):** Hot-pluggable LLM integration when `GEMINI_API_KEY` is provided to unlock multimodal visual PDF parsing and dynamic conversational depth.

### 2. Enterprise Scalability & Automation
* **Automated n8n Webhook Pipeline:** Automatically ingests batch candidate CSVs, dispatches personalized timed viva defense links to student inboxes, and delivers luxury HTML credentials upon completion.
* **Enterprise Admin Security Gateway:** Protected by a secure administrative authentication barrier (`admin` passkey), separating recruiter governance (AI tolerance gates, batch rosters) from candidate defense views.
* **Zero Infrastructure Overhead:** Lightweight async FastAPI backend (sub-50ms latency) with React 19 / Vite client.

## Slide 5: Research and References

### 1. Scientific & Methodological Foundations
* **McCabe Cyclomatic Complexity (IEEE TSE):** Applied via AST traversal to objectively quantify procedural logic complexity and branch density without dynamic execution risks.
* **Software Evolution & Commit Cadence Analysis (Empirical SE):** Research confirms authentic software engineering exhibits high refactoring churn ($>15\%$ code deletions), whereas cloned or AI-dumped projects exhibit $>95\%$ additive burst commits.
* **Counterfactual Fairness in AI Hiring (ACM FAccT):** Foundation for our **Recruiter Bias Mirror**, which masks institutional tiers to measure and systematically eliminate pedigree bias.
* **Text Burstiness & Stylometry (AI Detection):** Combines normalized TF-IDF term frequencies with burstiness variance metrics to identify robotic LLM prompt dumps during the timed viva.
